# PixelChat (Beta 0.91)

Лёгкий и быстрый мессенджер, который работает даже без интернета — напрямую между устройствами по Bluetooth.
## ✨ Основные возможности
* **Работа без сети:** Общение по Bluetooth без Wi-Fi и мобильного интернета.
* **Минимальный вес:** Приложение весит всего 3.45 МБ и не нагружает батарею.
* **Простой интерфейс:** Ничего лишнего — только быстрые чаты.
